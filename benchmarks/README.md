# FLEURS ASR benchmark

This directory evaluates transcripts generated by any ASR system against the
[FLEURS](https://huggingface.co/datasets/google/fleurs) reference transcript.
It compares raw scoring with Whisper basic normalization, a
mark-preserving basic mode, and a supported language-specific normalizer.

Install the one optional dependency and create a JSONL file using FLEURS
example IDs. Every example in the requested split must be present.

```sh
uv pip install --python .venv/bin/python datasets
```

```json
{"id": "123", "prediction": "model transcript"}
```

```sh
.venv/bin/python benchmarks/fleurs.py --language hi_in --split test \
  --predictions predictions.jsonl --output fleurs-hi_in-test.json
```

The JSON report has corpus-level WER and CER plus their substitution,
deletion, insertion, and reference-length counts. Supported
language-specific FLEURS configurations are `en_us`, `bn_in`, `gu_in`,
`hi_in`, `kn_in`, `ml_in`, `mr_in`, `or_in`, `pa_in`, `ta_in`, and `te_in`.
